Connection diagnostics
  • The page must be served from localhost or HTTPS; opening it as a file will not work.
  • On Arch-derived systems, serial devices normally use the uucp group.
  • The central half must produce a /dev/ttyACM* device when connected.
  • Only one browser tab or native process can own the serial port.
