        Connection diagnostics
        
      
          
    • The page must be served from localhost or HTTPS (the hosted tuner is HTTPS); opening it as a file will not work.
      • 
          
    • On Arch-derived systems, serial devices normally use the uucp group.
      • 
          
    • The central half must produce a /dev/ttyACM* device when connected.
      • 
          
    • Only one browser tab or native process can own the serial port.
      • 
          
    • Bluetooth needs firmware with the Bluetooth transport, and this computer must already be paired (bonded) with the keyboard's central half. Choose the keyboard in the browser's picker even while it's connected as a keyboard.
      • 
          
    • On Linux, Chrome may need Experimental Web Platform features turned on in chrome://flags before Web Bluetooth is available.
